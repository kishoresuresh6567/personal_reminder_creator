# Personal Reminder User Story Refinement

Use this skill when turning rough idea or GitLab issue into a Cursor-ready implementation story.

## Output

Return:

-Refined user story
-Acceptance criteria
-Data operations
-UI requirements
-API requirements
-Test cases
-Open questions

## Rules

-Keep the story small.
-Use personal reminder examples only.
-Ask questions if user role, data behavior, or expected output is unclear.
-Do not generate code during refinement.
